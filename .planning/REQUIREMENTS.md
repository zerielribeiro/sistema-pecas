# Requisitos do Sistema

## 1. Gestão de Inventário (Peças)
- [x] Cadastro de peças com código PCA único.
- [x] Listagem com agrupamento por descrição/status.
- [x] Filtro de peças por status (Estoque, Técnico, DOA).

## 2. Distribuição de Peças
- [x] Seleção de múltiplas peças para distribuição.
- [x] Busca e seleção de técnicos (Combobox).
- [ ] Confirmação de recebimento pelo técnico (Pendente/Opcional).

## 3. Laboratório (DOA)
- [x] Marcar peças como defeituosas/DOA.
- [x] Listagem de peças no laboratório com identificação do técnico de origem.
- [x] Geração de relatório PDF profissional com assinaturas.

## 4. Gestão de Usuários
- [x] Cadastro de técnicos e gestores.
- [x] Controle de acesso baseado em roles.

## 5. Estabilidade e UX
- [ ] Correção de erros de hidratação e roteamento (Next.js 16).
- [ ] Interface responsiva para técnicos em dispositivos móveis.
- [ ] Sincronização offline/PWA funcional.
