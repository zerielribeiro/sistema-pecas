# GestorRB - Gerenciamento de Peças e Assistência Técnica

## Visão Geral
O **GestorRB** é um sistema especializado em controle de inventário e rastreabilidade de peças para assistência técnica. O foco central é garantir que cada componente (identificado pelo seu PCA) seja monitorado desde a entrada no estoque até sua instalação final ou retorno ao laboratório como peça DOA.

## Objetivos Estratégicos
- **Rastreabilidade Total**: Garantir o histórico completo de posse e status de cada peça.
- **Eficiência na Distribuição**: Simplificar o fluxo de entrega de peças para técnicos em campo.
- **Gestão de Laboratório**: Controlar o recebimento e análise de peças defeituosas (DOA) com geração de relatórios formais.

## Stack Tecnológica
- **Frontend**: Next.js 16.2.4 + React 19
- **Backend**: Supabase (Auth, DB, SSR)
- **UI**: Tailwind CSS v4, shadcn/ui, Base UI

## Público-Alvo
- Gestores de estoque/laboratório.
- Técnicos de campo.
