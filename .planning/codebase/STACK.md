# Tech Stack

## Core
- **Framework**: Next.js 16.2.4 (experimental/canary version)
- **Library**: React 19.2.4
- **Language**: TypeScript 5.x

## Backend & Data
- **Platform**: Supabase
- **SDK**: `@supabase/supabase-js`, `@supabase/ssr`
- **Logic**: Next.js Server Actions (`src/app/actions`)

## UI & Styling
- **CSS**: Tailwind CSS v4
- **Components**: 
  - shadcn/ui (Radix/Base UI foundations)
  - `@base-ui/react` (Headless UI components)
- **Icons**: `lucide-react`
- **Animations**: `tw-animate-css`, `class-variance-authority`
- **Themes**: `next-themes`

## Utilities
- **Date Handling**: `date-fns`
- **PDF Generation**: `jspdf`, `jspdf-autotable`
- **Notifications**: `sonner`
- **PWA**: `@ducanh2912/next-pwa`
